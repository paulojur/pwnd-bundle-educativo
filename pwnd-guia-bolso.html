PWND!

Glossário Absoluto de Cartas

Um guia de estudo para o Host conhecer a explicação real (Bug Bounty) por trás de todas as mecânicas, ferramentas e vulnerabilidades de PWND!

🛠️ Ferramentas & Bypass

🧰 Tool Cards (Ferramentas de Bancada)
🗣️ Pitch Geral de Tools: "As tools são as extensões que nós hackers usamos. Você gasta tempo instalando elas (descartando cartas), mas depois elas automatizam o trabalho sujo. Um Burp Suite Pro, por exemplo, custa $400 por ano na vida real, no jogo te dá o poder de ignorar os bloqueios básicos do programa!"
Burp Suite Pro Epic
Universal Interception Proxy
Efeito: Ignore a régua de cores do programa ao baixar vulnerabilidades.
Ensino: É a ferramenta mais famosa do mundo hacker. Intercepta todas as requisições entre o navegador e o servidor. Literalmente "Ignora as regras padrão".
Nmap + ffuf Common
Network & Fuzzing Scanner
Efeito: +1 carta na ação de Recon (compra 3 em vez de 2).
Ensino: Nmap varre portas (ex: porta 80, 443, 22), ffuf descobre diretórios escondidos tipo /admin. Por isso te dá mais "cartas" de reconhecimento.
OWASP ZAP Common
Automated Vulnerability Scanner
Efeito: Baixe 2 vulns na mesma ação de Exploit.
Ensino: É um robô de scanner gratuito da OWASP que joga lixo nas aplicações tentando achar falhas de forma massiva. Acelera os exploits.
Postman API Suite Common
API Testing Environment
Efeito: Facilita baixar cartas de Broken Access Control.
Ensino: Plataforma para montar e testar chamadas de API (REST/GraphQL) no qual você testa permissões e autorizações cruzadas.
Browser DevTools Common
F12 Client-Side Analysis
Efeito: Dobra o valor de recompensas XSS.
Ensino: O famoso "Apertar F12 no Chrome". A aba Network e Console são as maiores aliadas para caçar XSS e falhas de front-end.
SQLMap Automator Uncommon
Database Injection Tool
Efeito: Ignora barreiras para baixar Injections.
Ensino: Um script python famosíssimo. Você dá a URL pra ele, vai tomar um café, e ele extrai o banco de dados inteiro sozinho testando injeções SQL.
Burp Collaborator Rare
Out-of-band Auditor
Efeito: Resgata ferramenta quando oponentes reportam SSRF.
Ensino: É um servidor que escuta interações "fora da banda" (OOB). Se o servidor da empresa pingar o seu Collaborator às escondidas, você comprova a falha (SSRF).
CyberChef Uncommon
Cyber Swiss Army Knife
Efeito: Converte cartas de ferramentas descartadas.
Ensino: "O canivete suíço". Uma ferramenta web mágica para decodificar base64, AES, Hex e criar cadeias lógicas de descriptografia.
JWT Tool Uncommon
Token Engineering Harness
Efeito: +50% bônus em vulnerabilidades de Autenticação.
Ensino: Tokens JWT são o padrão moderno de login. Eles contêm dados codificados em base64. Ferramentas que adulteram JWT são críticas para falsificar logins.
🛡️ Defuse & Bypass (Salvadores de Vidas)
Safeguard (Bypass) Rare
Zero-Day Reserve / WAF Bypass
Efeito: Anula 100% o efeito destrutivo do Patch Deployed.
Ensino: Representa um Exploit 0-Day não documentado que o hacker guardou na manga, ou um Bypass de firewall que ele puxa em caso de emergência. A empresa lança o patch, mas o hacker usa o Bypass e ainda continua conectado!
CVE Assignment Protection Uncommon
CVE Authority Reservation
Efeito: Anula o Duplicate Report (10% de pena) e ataques OOS.
Ensino: O MITRE emite os números "CVE" oficiais. Se você já reservou um CVE para a sua falha, você tem o direito oficial sobre ela, mesmo que outros reclamem. Impede burocracias!

🔥 80 Vulnerabilities (CVSS)

🗣️ Pitch de Severidade: "Toda vulnerabilidade tem o CVSS (Common Vulnerability Scoring System, de 0 a 10). Se é Cinza (Common), paga mal e é falha simples. Se é Roxa/Laranja (Epic/Legendary, de 9.0 a 10.0), a empresa tá perdendo dados e você será pago com valores altíssimos."
💉 Injection (16 Cartas)
Injeção de Boato Common
SQL Injection (SQLi)
Você cochicha um boato falso no campo de texto e o banco de dados acredita, entregando as senhas.
A Injeção da Vovó Rare
Classic SQLi (OR 1=1)
A mais famosa. ' OR '1'='1 — Entrando como se fosse da família.
Sopa de Comandos Common
OS Command Injection
Insere comandos de sistema operacional diretamente no input do usuário.
A Entidade Fantasma Common
XXE Injection
O parser XML lê arquivos confidenciais locais do servidor.
O Operador Vazado Uncommon
NoSQL Injection
Bypassa autenticação injetando operadores de lógica ($gt, $ne) no MongoDB.
A Bomba-Relógio Rare
Time-Based Blind SQLi
Injeção às cegas baseada em atraso. Força o servidor a pausar (SLEEP 10) para extrair dados lentamente char-by-char.
O Veneno Lento Rare
Second-Order SQLi
O payload é injetado, mas só explode no mês seguinte quando o admin gerar o relatório.
O Tubo Estourado Legendary
Critical Database Takeover
CVSS Altíssimo. Acesso root à instância mestra do banco relacional de dados.

(E outras cartas de LDAP, ORM, SSTI...)

🚪 Broken Access Control (14 Cartas)
Ensino rápido: BAC é quando o usuário A consegue ver ou editar coisas do usuário B sem ter permissão. Inclui IDOR e Escalada de Privilégio.
Porta Escancarada Common
Insecure Direct Object Reference (IDOR)
Você altera a URL de id=10 para id=1 e acessa a conta do dono.
O Plebeu Privilegiado Common
Privilege Escalation (PrivEsc)
O estagiário intercepta o request, injeta "role": "admin" e vira o chefe do sistema.
O Corredor Secreto Common
Directory Traversal (Path Traversal)
Usa ../../../etc/passwd para acessar pastas raízes proibidas pelo navegador.
O Elevador de Serviço Uncommon
Broken Function Level Auth
Você acessa /admin/delete_all_users adivinhando o link. Ninguém exigiu a senha.
O Degrau Oculto Rare
JWT Role Manipulation
Você adultera seu Token de sessão localmente assumindo a função de Superadmin.
A Sala do Trono Legendary
Root Organization Takeover
CVSS extremo! Acesso completo ao painel corporativo da matriz. Controle total.
🪞 Cross-Site Scripting - XSS (12 Cartas)
Ensino rápido: Injetar scripts de JavaScript que rodam no navegador da vítima. Rouba cookies, tokens e clicks.
Espelho Falso Common
Reflected XSS
O script malicioso vai na URL (ex: um link falso que você manda por e-mail). Se clicarem, você ganha.
O Labirinto de Espelhos Common
DOM-based XSS
Falha ocorrendo exclusivamente no JavaScript do cliente (SPA/React), sem tocar no servidor.
O Reflexo Congelado Uncommon
Stored XSS
Você posta um comentário no fórum contendo o Script. Quem ler o post, tem a conta hackeada automaticamente.
A Tinta Invisível Uncommon
Markdown Parser XSS
Você escapa do parser de markdown no chamado de suporte técnico. O suporte lê, o script executa e rouba a sessão de suporte.
O Fio Transparente Epic
WebSocket XSS Hijack
Exploração avançada roubando tokens de autenticação em tempo real via canal persistente.
🔐 Authentication Flaws (10 Cartas)
Chave Mestra Common
Authentication Bypass
Ignora o prompt de senha totalmente através de brecha lógica.
O Porteiro Esquecido Common
Persistent Session Leak
O token de "Lembrar de Mim" nunca expira e permite reuso ilimitado em terminais expostos.
O Distintivo Falso Uncommon
JWT Alg None Bypass
Altera a assinatura do token para algoritmo "none", enviando um crachá de identificação em branco aprovado por falha lógica.
O Gêmeo Maligno Uncommon
OAuth CSRF / State Fixation
Vincula a rede social da vítima à sua própria conta devido à ausência do parâmetro protetor "state".
O Guarda Distraído Rare
Multi-Factor Auth (MFA/2FA) Bypass
Força bruta no SMS enviando milhares de requisições paralelas sem acionar limite de tentativas.
O Sósia do Executivo Epic
SAML Response Tampering
Engana o protocolo Single Sign-On (SSO) da matriz da empresa, assumindo papel executivo corporativo.
🕵️ SSRF (8 Cartas)
Ensino rápido: Server-Side Request Forgery. Você força o próprio servidor da empresa a fazer o que você quer internamente, burlando firewalls, já que ele confia em si mesmo.
O Espião Interno Common
Classic SSRF
Pede pro servidor público acessar e devolver a página restrita 127.0.0.1 (Localhost).
O Segredo do Servidor Uncommon
AWS EC2 Metadata SSRF
Acesso clássico de bug bounty ao endpoint mágico 169.254.169.254, que devolve as chaves e credenciais IAM limpas do servidor de nuvem.
O Endereço Traiçoeiro Rare
DNS Rebinding
O DNS resolve prum IP limpo, passa pela verificação e, segundos depois, resolve prum IP restrito pra realizar a requisição!
O Mensageiro Cego Epic
Gopher SSRF to Redis RCE
Você injeta uma chave SSH forjada através do protocolo Gopher diretamente dentro do banco Redis.
💸 Business Logic (8 Cartas)
Ensino rápido: Não é código quebrado, é regra de negócio falha! Como o fato de o site aceitar sacar valor negativo (e dar o troco pra ti).
O Troco Infinito Common
Negative Amount Logic Flaw
Você põe no carrinho "-5 unidades" de um TV. O saldo da compra dá negativo. A loja paga você o valor do produto na finalização.
A Entrega Fantasma Uncommon
Race Condition
Com $10 na conta, você ativa um script que aperta o botão "Sacar $10" 50 vezes simultâneas. O banco saca $500 antes do seu saldo zerar no sistema.
O Carrinho Sem Fundo Rare
Integer Overflow
Soma tantos itens (estourando o número binário 2.147.483.647) que o valor volta a ser zero ou negativo.
🔏 Cryptographic & Legendary RCE (12 Cartas)
Ensino rápido: Erros de criptografia (MD5 fraco sem salt, Padding Oracles) e os Reis da Coroa: "RCE" ou Remote Code Execution, que ditam os maiores bounties do mundo.
Cadeado de Papel Common
Weak Crypto (MD5)
Senhas vazadas são encontradas em 2 segundos em sites de crack MD5 porque não têm "Salt" (randomização).
O Oráculo Fofoqueiro Rare
CBC Padding Oracle
Decodifica mensagens cifradas brincando com os erros que o servidor cospe.
A Tempestade Perfeita Rare
Multi-Stage Chain Exploit
Combinação! Você encadeia SSRF para acessar o painel Admin e jogar um RCE lá dentro.
O Mestre dos Títeres Legendary
Remote Code Execution (RCE)
O prêmio máximo: você controla o servidor. É a vulnerabilidade que garante os bounties de $10.000 a $100.000+ no mundo real!
A Caixa de Pandora Legendary
Log4Shell / Java Deserialization
Referência ao Log4J. Piora absoluta. Controle de infraestrutura cloud instantânea apenas logando string maliciosa.

🌪️ 24 Eventos (O Caos Corporativo)

🗣️ Pitch Geral: "Bounty Hunters odeiam duas coisas: Duplicates (perder a recompensa pra quem chegou 5 minutos mais cedo) e burocracia (Out of Scope, filas eternas). O baralho de Eventos simula essa frustração PvP constante da profissão."
💥 Disrupção PvP e Ataques (8 Cartas)
Duplicate Report!
Duplicated Vulnerability Submission
Efeito: Oponente descarta a vulnerabilidade de maior valor da mesa.
Ensino: 90% da dor de um hacker. O status passa de 'Triage' para 'Closed as Duplicate'. Sem dinheiro, sem glória.
DNS Hijack!
Compulsory Target Switch
Efeito: Altera o programa ativo do oponente (ele perde os exploits!).
Ensino: Tráfego desviado. De repente, todo o escopo no qual você trabalhou desapareceu do mapa ou foi migrado.
Honeypot Triggered!
Decoy Server Trap
Efeito: Oponente descarta 2 cartas da mão.
Ensino: Era um servidor falso plantado pelo Blue Team só pra estudar suas táticas e queimar seu tempo.
Data Breach! & Security Audit!
Compliance Hand Inspection
Efeito: Exposição da mão e perda das cartas Críticas/Maior CVSS.
Ensino: Vazamento ou auditoria pesada obriga quebra da confidencialidade da pesquisa.
⏳ Burocracia e Escopo (8 Cartas)
Out of Scope!
Boundary Rejection
Efeito: O Autor não pode jogar ação Exploit no próximo turno.
Ensino: O famigerado "Informational" ou "Out of Scope" do HackerOne. Você reportou um erro em subdomínio que não faz parte do bounty.
Legal Threat! (Cease & Desist)
Corporate Lawyer Intervention
Efeito: Bloqueia a ação Report por 1 rodada do alvo.
Ensino: "Parem os testes já ou processaremos." Você tocou num mainframe frágil e a empresa mandou o jurídico!
Triage Delay!
Corporate Backlog Delay
Efeito: O autor joga com a mão revelada na mesa até o próximo turno.
Ensino: A triagem corporativa dormiu e não viu seu relatório, a falha vazou e agora a comunidade tá lendo suas táticas.
WAF Deployed! / 2FA Enforced!
Web App Firewall / Hardening
Efeito: Bloqueiam classes específicas de vulnerabilidades de serem armadas (Injection / Authentication).
Ensino: O Blue Team ativou a defesa da Cloudflare e subitamente SQLMap parou de funcionar e tudo dá 403 Forbidden.
💰 Bônus e Comunidade (8 Cartas)
Bounty Increase! & Bug Bounty Mediation
Double Bounty Multiplier
Efeito: Injeção massiva de dólares (bônus de 50% ou flat money).
Ensino: Às vezes, o CISO adorou o seu trabalho e multiplicou seu Bounty. Mediação é quando o HackerOne força um pagamento amigável.
Responsible Disclosure!
Instant Free Submission
Efeito: Report Imediato em toda a mesa sem rolar o D8.
Ensino: Divulgação ética! A janela onde tudo dá certo, a empresa assume a falha e paga todo mundo que enviou sem correr o risco de Patch.
Bug Bounty Conference! & Swag Drop!
Global Networking Event
Efeito: Compra cartas (Tools e Main Deck) globalmente.
Ensino: Encontros como DEF CON, Black Hat e H2HC. Todo mundo volta mais forte, com camisas, adesivos e truques novos.
Zero Day Disclosure
Underdog Catch-Up
Efeito: O último colocado pega uma vulnerabilidade do lixo.
Ensino: Vazam um 0-day no Twitter. Quem estava desatento usa ele para escalar os privilégios e correr atrás do pódio!
